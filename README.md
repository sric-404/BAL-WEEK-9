# Week 9 Sales and Profit Dashboard

## Objective

Create an interactive Tableau dashboard to analyze sales and profit performance across time, product categories, and customer segments.

## Tools Used

- Tableau Public
- Sales dataset
- GitHub

## Dashboard

[View the interactive Tableau dashboard](https://public.tableau.com/app/profile/sri.chandan8319/viz/BALWEEK9/Dashboard1)

The dashboard contains the following visualizations:

- **Monthly Sales Trend** — shows how sales change over the months.
- **Sales by Category and Customer Segment** — compares sales across categories and customer groups.
- **Sales Distribution by Category** — displays the contribution of each product category.
- **Sales vs. Profit Analysis** — shows the relationship between sales and profit.

## Tasks Performed

- Connected the dataset to Tableau Public.
- Created worksheets for sales, profit, category, segment, and monthly analysis.
- Compared category and customer-segment performance.
- Analyzed the relationship between sales and profit.
- Combined the worksheets into a single interactive dashboard.

## Conclusion

The dashboard provides a clear overview of sales and profitability. It helps identify monthly trends, compare product-category and customer-segment performance, and evaluate whether higher sales are producing stronger profits.
